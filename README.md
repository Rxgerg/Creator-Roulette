# Creator Roulette

Creator Roulette es una aplicación de escritorio configurable pensada para creadores de contenido, streamers y comunidades gaming.

La idea principal es permitir crear ruletas personalizadas para elegir roles, personajes, retos, preguntas o dinámicas aleatorias durante streams o grabaciones. Aunque nace pensando en juegos como League of Legends, la app está diseñada para poder adaptarse a cualquier comunidad o videojuego.

El objetivo es que cada creador pueda modificar los textos, listas, retos y configuraciones sin tener que tocar el código.
